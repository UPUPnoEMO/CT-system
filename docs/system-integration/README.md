# 系统集成 · System Integration

> CT 系统的系统集成涵盖扫描架机械、高压发生器、探测器模块、数据采集（DAS）、图像重建计算机等子系统的协同工作，是整机性能的关键决定因素。

---

## 1. CT 图像重建算法

### 1.1 核心重建算法（从投影数据到断层图像）

#### 滤波反投影（FBP）

- **原理**：最经典、应用历史最久的算法。对投影数据做滤波（卷积运算）校正模糊，再反投影回图像空间合成断层图像。
- **特点**：速度快，是绝大多数 CT 的默认基础算法；但低剂量下噪声大。
- **适用**：常规剂量头部/体部平扫。

#### 迭代重建（IR）

- **原理**："猜测-比较-修正"循环。先假设初始图像，计算其模拟投影，与真实投影对比，不断调整优化，使模拟数据逼近真实数据。
- **特点**：能精确建模系统物理特性和噪声统计，低剂量下噪声抑制显著优于 FBP。
- **适用**：**低剂量 CT 扫描**（肺癌筛查、儿童检查）。

#### 基于 AI 的重建算法

- **原理**：利用深度学习（CNN）学习"低质量投影→高质量图像"的映射关系，直接从稀疏/低剂量数据重建高质量图像。
- **特点**：超低剂量或稀疏投影下优势显著；是目前最前沿的方向。
- **适用**：超低剂量检查、冠状动脉 CTA（减少辐射+保留诊断准确性）。

### 1.2 图像后处理与三维可视化

| 技术 | 原理 | 典型应用 |
|------|------|---------|
| **多平面重建（MPR）** | 将连续横断面图像重新组合，生成冠状位/矢状位/任意斜位 2D 图像 | 脊柱矢状位观察椎体滑脱/间盘突出 |
| **最大密度投影（MIP）** | 沿观察方向取最高 CT 值体素投影到 2D 平面 | 脑部 CTA 显示血管、动脉瘤 |
| **表面阴影遮盖（SSD）** | 设定 CT 值阈值提取表面，模拟光线照射生成 3D 模型 | 面部骨折术前规划 |
| **容积漫游技术（VRT）** | 保留所有体素，不同 CT 值赋予不同透明度和颜色 | 肺部肿瘤与血管/支气管关系展示 |
| **曲面重建（CPR）** | 沿手动/自动曲线将弯曲结构"拉直"展开为 2D | 冠状动脉、胆总管、输尿管评估 |
| **虚拟内镜（VE）** | 模拟内窥镜视角在空腔脏器内"飞行漫游" | CT 结肠成像（结肠癌筛查）|

## 2. CT 扫描参数详解

### 2.1 采集参数（扫描参数）

| 参数 | 定义 | 主要影响 | 典型值 |
|------|------|---------|--------|
| 管电压 (kV) | X 射线管两极电压 | 穿透力、对比度、剂量 | 80/100/120 kV |
| 管电流 (mA) | X 射线管灯丝电流 | 图像噪声、剂量 | 30-300 mA |
| 管电流时间积 (mAs) | mA × 扫描时间 | **噪声与剂量的核心** | 自动调制 |
| 螺距 (Pitch) | 床速 / (单圈时间 × 探测器宽度) | 扫描速度、剂量 | 0.8-1.375 |
| 旋转时间 | 旋转一周时间 | 时间分辨率（心脏） | 0.25-1.0 s |
| 探测器宽度 | Z 轴物理宽度 | 单圈覆盖范围、Z 轴分辨率 | 40-160 mm |
| 扫描视野 (FOV) | 成像区域直径 | 空间分辨率 | 15-50 cm |

### 2.2 重建参数

| 参数 | 定义 | 主要影响 |
|------|------|---------|
| 重建层厚 | 横断面图像厚度 | Z 轴分辨率、噪声 |
| 重建视野 (RFOV) | 显示区域直径 | 有效空间分辨率（数字放大）|
| 重建算法（卷积核）| 滤波函数 | **图像锐利度与噪声**：软组织用平滑核，骨/肺用锐利核 |
| 迭代重建权重 | 噪声抑制强度 | 降噪与图像纹理保真度的平衡 |
| 窗宽/窗位 (WW/WL) | 显示灰度映射 | **必须根据观察组织调节**：脑窗 WW80/WL40，肺窗 WW1500/WL-600 |

### 2.3 自动管电流调制（AutomA）

- **原理**：基于定位像获取患者体型信息，实时计算并输出每一角度所需 mA，保持图像噪声恒定。
- **类型**：Z 轴调制（最常见）、角度（X-Y）调制、ECG 门控调制（心脏 CTA）。
- **价值**：个性化降低辐射剂量，稳定图像质量。

## 3. CT 图像质量与伪影

### 3.1 图像质量相关因素

| 因素 | 受影响参数 |
|------|-----------|
| 空间分辨率 | 探测器大小、层厚、DFOV、矩阵数、重建算法 |
| 密度分辨率 | 散射线、kV、噪声（与 mAs 相关）|
| 噪声 | mAs、迭代重建、滤波算法、层厚 |
| 部分容积效应 | 层厚、层间距 |
| 半影 | 焦点大小、层厚 |

### 3.2 伪影类型与防治

| 伪影类型 | 成因 | 防治方法 |
|---------|------|---------|
| 光子不足 | X 线光子数量不够 | 适当增加 mAs |
| 线束硬化 | X 线能量差异导致 | 使用滤过器、特殊重建算法校正 |
| 金属伪影 | 金属高密度吸收差异 | 去除金属、金属伪影校正算法、增加 kV |
| 截断伪影 | 扫描范围不完整 | 合理设计扫描范围、选择合适的重建算法 |
| 运动伪影 | 患者呼吸/心跳/蠕动 | 屏气指导、心电门控、药物抑制 |
| 设备伪影 | 球管放电/故障 | 定期维护、及时更换老化部件 |

## 4. CT 探测器串扰抑制

| 串扰类型 | 核心成因 | 硬件方案 | 软件方案 |
|---------|---------|---------|---------|
| **光学串扰** | 闪烁体荧光光子散射、隔离层光学性能不足 | 高折射率匹配闪烁体+低散射光导；像素间高反射隔离层（TiO₂涂层）| 邻域像素信号串扰矩阵校正；空间滤波算法 |
| **电荷串扰** | 高剂量下载流子扩散、电路寄生电容耦合 | 深沟槽隔离（DTI）结构；优化 ASIC 布局减小寄生电容 | 高剂量区域非线性补偿；电容耦合模型解耦算法 |

## 5. 国产 CT 市场格局

### 5.1 市场总体格局（2024 年）

- **国产化率**：从 2019 年 11% 快速提升至 2024 年 **36%**
- **第一梯队**：联影医疗（~29% 份额）、东软医疗（~11% 份额）
- **第二梯队**：明峰医疗、万东医疗、安科
- **国际巨头**：GE、西门子、飞利浦、佳能（高端技术话语权仍强）

### 5.2 核心五巨头对比

| 企业 | 技术标签 | 核心产品/里程碑 | 发展战略 |
|------|---------|---------------|---------|
| **东软医疗** | 全链条自研、核心部件可控 | 全球首台 8cm 宽体光子计数 CT NeuViz P10（2025）| 高端突破 + 国际化"走上去" |
| **联影医疗** | 全面创新、平台化布局 | 超 190 款产品，全产业链生态 | 预防→诊断→治疗→康复全流程生态 |
| **万东医疗** | 临床可靠性、流程智能化 | TurboTom 3 S（液态金属轴承球管）| 基层优势 + 高端医院进军 |
| **明峰医疗** | 专注中高端、高研发投入 | 256 排超高端 CT | 国产替代 + 区域化布局（云贵川/东南亚）|
| **安科** | 细分市场参与者 | — | 持续 CT 布局 |

### 5.3 未来竞争焦点

1. **技术竞赛升维**：从探测器排数转向**能量成像与光子计数**（东软已率先推出产品）
2. **商业模式演进**：从单一设备销售向 **"一站式诊疗解决方案"** 转型
3. **市场全球化**：联影、东软建立全球网络，参与国际竞争
4. **产业生态分化**：颠覆性硬件创新（Nanox、Brainlab）+ 独立 AI 软件崛起

### 5.4 CT 设备价格谱系

| 层级 | 价格区间 | 代表产品 |
|------|---------|---------|
| 基层/入门（32-64 排）| 200-400 万元 | — |
| 中高端（64-128 排）| 300-700 万元 | — |
| 高端/超高端（256 排+）| 1000-2000 万元 | — |
| 尖端（光子计数 CT）| 4000-6000 万元 | 西门子 NAEOTOM Alpha |
