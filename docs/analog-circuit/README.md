## PN结

### PN结的形成

1. 掺杂类型与杂质原子

- N型半导体：在本征硅中掺杂五价元素（如磷P、砷As）。
  - 磷原子有5个价电子，其中4个与周围硅原子形成共价键，多余的一个电子极易脱离原子核束缚成为自由电子。
  - 磷原子失去电子后成为固定在晶格中的正离子（P⁺），称为“正电中心”。此时，自由电子是多数载流子（多子），空穴是少数载流子（少子）。
- P型半导体：在本征硅中掺杂三价元素（如硼B、镓Ga）。
  - 硼原子有3个价电子，在与周围硅原子形成共价键时，缺少一个电子，形成一个“空位”（即空穴）。
  - 硼原子容易从邻近硅原子获得一个电子，自身成为固定在晶格中的负离子（B⁻），称为“负电中心”。此时，空穴是多子，电子是少子。

2. 扩散与漂移

- 多子的扩散运动：
  - 由于P区和N区存在载流子浓度差，P区的空穴会向N区扩散，N区的电子会向P区扩散。
  - 扩散的结果是：在P区和N区交界面附近，P区留下不可移动的负离子（B⁻），N区留下不可移动的正离子（P⁺），形成空间电荷区（即PN结或耗尽层）。
- 内建电场的形成与少子的漂移：
  - 空间电荷区产生的电场方向为从N区指向P区，这个电场称为内建电场。
    内建电场会阻碍多子的扩散运动，同时促进少子的漂移运动（P区的电子向N区漂移，N区的空穴向P区漂移）。

3. 动态平衡

- 在无外加电压时，扩散运动与漂移运动最终达到动态平衡：
  - 扩散电流（多子形成）与漂移电流（少子形成）大小相等、方向相反。
    此时净电流为零，空间电荷区的宽度和电势差保持稳定。

4. 外加偏压的影响

- 正向偏压（P区接正，N区接负）：
  - 外电场削弱内建电场 → 空间电荷区变窄​ → 扩散运动占优势 → 形成较大的正向扩散电流。
- 反向偏压（N区接正，P区接负）：
  - 外电场增强内建电场 → 空间电荷区变宽​ → 漂移运动占优势 → 形成很小的反向漂移电流（饱和电流）。
