# 模拟电路 · Analog Circuit

> 模拟电路处理连续信号，是 CT 探测器前端读出（ASIC 模拟通道）、电源管理、传感器接口的核心基础。

---

## 1. PN 结

### 1.1 PN 结的形成

**掺杂类型**：

| 类型 | 掺杂元素 | 多子 | 少子 | 电中心 |
|------|---------|------|------|---------|
| N型 | 五价（磷P、砷As）| 电子 | 空穴 | 正电中心（P⁺）|
| P型 | 三价（硼B、镓Ga）| 空穴 | 电子 | 负电中心（B⁻）|

**动态平衡**：
- 扩散运动（多子）→ 形成空间电荷区（耗尽层）
- 漂移运动（少子）→ 内建电场（N→P）
- 平衡时：扩散电流 = 漂移电流，净电流 = 0

**外加偏压**：
| 偏压 | 内建电场 | 空间电荷区 | 电流 |
|------|---------|------------|------|
| 正向（P正N负）| 削弱 | 变窄 | 大（扩散电流）|
| 反向（N正P负）| 增强 | 变宽 | 小（漂移/饱和电流）|

## 2. 二极管

### 2.1 二极管特性

- **正向特性**：电压 > 门槛电压（Si: ~0.5V, Ge: ~0.1V）后电流急剧增大
- **反向特性**：反偏时电流极小（饱和电流）；电压过大则击穿
- **齐纳二极管**：反向击穿后可恢复，用于稳压
- **雪崩二极管**：高反压击穿，用于过压保护

### 2.2 二极管的等效电路

- **直流等效**：理想二极管（正向0压降/反向∞电阻）或实际模型（正向压降Vf、反向漏电流Ir）
- **微变等效（交流小信号）**：正向偏置下，rd = VT/ID（动态电阻）
- **稳压二极管等效**：反向击穿区，齐纳阻抗ZZ

### 2.3 双极晶体管（BJT）结构与放大原理

**结构**：发射区（E）、基区（B，极薄）、集电区（C）

| 极性 | 发射结 | 集电结 | 工作模式 |
|------|---------|---------|---------|
| NPN | 正偏 | 反偏 | 放大模式 |
| NPN | 正偏 | 正偏 | 饱和模式 |
| NPN | 反偏 | 反偏 | 截止模式 |
| NPN | 反偏 | 正偏 | 反向放大（罕见）|

**放大原理**：发射结正偏 → 电子注入基区 → 大部分扩散到集电结 → 集电结反偏收集 → 实现电流放大（β = IC/IB）

### 2.4 BJT 特性曲线（共射极）

```
IC
 |   /
 |  /   工作区（放大区）
 | / 
 |----------- 截止区
 +---------------- IB
```

- **输出特性**：IC = f(VCE, IB)，分截止区、放大区、饱和区
- **输入特性**：IB = f(VBE, VCE)

## 3. MOS 管工作原理

### 3.1 结型场效应管（JFET）

- **结构**：PN 结栅极，反向偏置耗尽层控制沟道
- **特性**：电压控制电流，输入阻抗极高
- **类型**：N沟道（耗尽型默认导通）、P沟道

### 3.2 绝缘栅型场效应管（MOSFET）

| 类型 | 符号特点 | 默认状态 | 阈值电压 Vth |
|------|---------|---------|------------|
| N沟道增强型 | 箭头向里（衬底P）| 截止（VGS=0不通）| Vth > 0 |
| N沟道耗尽型 | 箭头向里，虚线沟道 | 导通（VGS=0导通）| Vth < 0 |
| P沟道增强型 | 箭头向外（衬底N）| 截止 | Vth < 0 |
| P沟道耗尽型 | 箭头向外，虚线沟道 | 导通 | Vth > 0 |

**MOS管放大原理**：VGS控制沟道宽度 → 控制ID → 电压放大（共源极接法）

## 4. 放大电路

### 4.1 放大电路的分析方法

| 分析项目 | 说明 |
|---------|------|
| 放大倍数 Au | Au = Uo/Ui |
| 输入电阻 Ri | 从输入端看进去的等效电阻，越大越好（减小信号源负载）|
| 输出电阻 Ro | 从输出端看进去的等效电阻，越小越好（带负载能力强）|
| 通频带 BW | 上限频率 fH - 下限频率 fL，由三极管特征频率 fT 决定 |
| 非线性失真 | 截止失真/饱和失真 |
| 最大不失真输出电压 | 受电源电压和晶体管特性限制 |
| 最大输出功率与效率 | Class A/B/AB/C 效率对比 |

**分析步骤**：
1. **直流通路**：电容开路、电感短路 → 求 Q 点（IBQ, ICQ, UCEQ）
2. **交流通路**：电源短路（内阻≈0）、电容短路 → 求 Au, Ri, Ro
3. **图解法**：在输出特性曲线上做负载线，求 Q 点和动态范围

### 4.2 常见放大电路类型

| 电路类型 | 特点 |
|---------|------|
| 共射放大 | 电压增益高，输入输出反相，Ri中等 |
| 共集放大（射随器）| 电压增益≈1，输入阻抗高，输出阻抗低，功率增益高 |
| 共基放大 | 电压增益高，电流增益≈1，高频特性好 |
| 阻容耦合放大 | 各级 Q 点独立，适合集成电路 |
| 直接耦合放大 | 可放大直流，有零点漂移问题 |

## 5. 电路基本原理

| 原理/方法 | 说明 |
|---------|------|
| 戴维南定理 | 线性有源二端网络 → 等效电压源+Vth+ Rth |
| 诺顿定理 | 线性有源二端网络 → 等效电流源+In+ Rn |
| 叠加定理 | 多电源线性电路，响应 = 各电源单独作用之和 |
| 最大功率传输 | RL = Rth 时负载获得最大功率 |
| 结电容 | PN 结耗尽层形成的电容，影响高频特性 |
| 寄生电容/电感 | 非设计意图的寄生参数，高频下影响显著 |
